## Run it

```sh
python3 main.py
```

This redraws the front page (1024×1024, deterministic — two runs produce
byte-identical output) from `news.json` and writes it to
`$MAKEFUN_OUTPUT_DIR/entry.png` (or `/output/entry.png`). It never writes
into the repository folder. All stories were first reported on
26 November 2026.
